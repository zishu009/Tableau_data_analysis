# 🚗 Electric Vehicle Market Analysis – Tableau

### 📅 Date: August 2024  
### 📊 Tool Used: Tableau

---

## 📌 Project Overview

This project focuses on analyzing the growing **Electric Vehicle (EV) market** using Tableau. The interactive dashboard helps uncover insights into EV adoption patterns, vehicle types, geographical distribution, and key performance metrics.

---

## 🎯 Objective

To build a dynamic Tableau dashboard that:
- Visualizes the adoption of electric vehicles across the U.S.
- Highlights trends in vehicle types, models, manufacturers, and states.
- Provides key insights to support clean energy initiatives and policy planning.

---

## 🔍 Key Insights

- **Total Records Analyzed:** 150K+ EVs  
- **Vehicle Type Distribution:**
  - **Battery Electric Vehicles (BEVs):** 77.6%
  - **Plug-in Hybrid Electric Vehicles (PHEVs):** 22.4%
- **Average Electric Range:** 67.83 miles
- **Top EV States:** California, Washington, Oregon
- **Popular Makes:** Tesla, Nissan, Chevrolet
- **Model Years:** Trend shows increasing adoption post-2018

---

## 📈 Dashboard Features

- Filters by **State**, **Model Year**, **Vehicle Type**, and **Make**
- KPIs highlighting **average range**, **vehicle type breakdown**, and **state-level adoption**
- Interactive charts and maps showing EV distribution and growth
